# tholos-nearbygame

This capacitor plugin is responsible for hosting and managing a lightweight game session for sharing level and bonuses between user

## Install

To use npm

```bash
npm install tholos-nearbygame
````

To use yarn

```bash
yarn add tholos-nearbygame
```

Sync native files

```bash
npx cap sync
```
